# 🍔 Food Delivery Data Analysis Dashboard

## 📌 Project Overview

This project analyzes a Food Delivery platform using SQL, Power BI, Excel, and Python.

The goal is to transform raw transactional data into meaningful business insights that help management make better decisions.

---

## 📊 Tools Used

- SQL
- Power BI
- Excel
- Python
- GitHub

---

## 📈 Dashboard Pages

- Executive Dashboard
- Restaurant Performance
- Customer Analytics
- Orders & Delivery Analysis
- Geographic Insights

---

## 📌 KPIs

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Completed Orders
- Delivery Success Rate
